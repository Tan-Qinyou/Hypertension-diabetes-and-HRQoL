# Hypertension-diabetes-and-HRQoL
Using KCHS (13 survey years, 2011 to 2025; n = 2,854,292) and KNHANES (16 survey years, 2007 to 2024; n = 88,553), we examined associations of hypertension and diabetes with five HRQoL domains in Korean adults, assessed consistency across surveys, and explored treatment associations and geographic and temporal patterns.
